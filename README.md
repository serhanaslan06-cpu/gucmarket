# GüçMarket MVP

Bu paket, GüçMarket'in konuştuğumuz konsepti için Next.js tabanlı bir başlangıç iskeletidir.

## Dahil
- Ana sayfa
- UPS / akü / OEM / solar ürün kategorileri
- Ürün listeleme ve detay sayfası
- Teklif Al akışı için UI
- Servis / bakım / arıza talebi formu
- Kullanıcı dashboard ve Cihazlarım örneği
- Satıcı/admin paneli başlangıç ekranları
- Responsive tasarım için temel yapı

## Henüz bağlanmamış kısımlar
- PostgreSQL/Supabase veritabanı
- Gerçek kullanıcı/firmа authentication
- Firma ürün CRUD işlemleri
- Gerçek teklif ve servis talebi kayıtları
- Dosya depolama
- Abonelik/iyzico/PayTR ödeme
- SMS/e-posta/WhatsApp entegrasyonu
- Admin onay mekanizması
- Gerçek arama ve gelişmiş filtreleme

## Çalıştırma
Node.js 20+ ile:

```bash
npm install
npm run dev
```

Sonra http://localhost:3000 adresini açın.
